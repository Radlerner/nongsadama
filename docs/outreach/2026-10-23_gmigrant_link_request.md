경기도 이주민 포털 커뮤니티(동부·서부·남부·북부)에는 이주민이 직접 쓴 지역 추천 글과 정책홍보단의 현장취재 글이 많아,
경기도에 사는 농사다마 이용자에게 이 글들을 안내하고 싶습니다. 포털 이용약관(제7조, 제9조)에 따라 게시물의 권리가 작성자와 포털에 있음을 알고 있어,
먼저 센터의 의견을 여쭙니다.

**1. 검토 중인 방식(원문 연결만)**
- 농사다마의 경기도 시·군 화면에 "경기도 이주민 포털의 이웃 이야기" 칸을 두고, 글 **제목·분류·등록일과 원문 주소만** 보여 줍니다.
  누르면 포털의 원문 화면으로 이동합니다.
- 글 본문·사진·작성자 별명은 옮기거나 저장하지 않고, 번역하거나 고쳐 쓰지 않습니다.
- 출처를 "경기도 이주민 포털(경기도이민사회통합지원센터)"로 표시합니다.
- 관리자 공지는 제외하고, 최근 글(예: 90일 이내)만 보여 줍니다.
- 작성자나 센터가 요청하면 해당 글의 연결을 바로 내립니다.

**2. 여쭙고 싶은 것**
1. 위 방식으로 원문을 연결해도 되는지, 지켜야 할 조건(출처 표시 문구, 로고 사용 여부, 빼야 할 게시판·분류)이 있는지.
2. 글 목록을 받는 방법: 지금은 공개된 목록 화면을 주 1회, 요청 사이 간격을 두고 읽는 방식을 생각하고 있습니다.
   센터가 원하는 방식(RSS, 목록 파일 제공, 공개 API 등)이나 빈도·범위 제한이 있으면 그대로 따르겠습니다.
3. 정책홍보단 카드뉴스의 다국어판이 있다면 언어별로 연결해도 되는지.
4. 협력할 수 있는 담당자와 연락 방법.
