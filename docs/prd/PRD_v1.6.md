## 2. 보는 지역(view)
- 기기 기록 `nongsadama.regionChoice`: 보는 지역과 출처(직접 고름 / 프로필을 따름 / 전국 / 없음), 고를 때의 계정. 다른 계정의 기록은 쓰지 않는다.
- 판단 순서: 적용되는 기록 → (로그인했고 기록이 없으면) 프로필 지역을 최대 5초 기다림 → 없음.
- 5초가 지난 뒤 온 프로필 지역은 자동 적용하지 않고 "내 지역(○○)으로 보기" 버튼만 켠다(점검 R6). 프로필 조회 실패·오프라인은 바로 안내(R7).
- 같은 계정의 토큰 갱신·탭 복귀로 다시 판단하지 않는다. 로그인을 확인하는 동안에는 기록을 읽기만 한다.
- 다른 기기에서 프로필 지역을 바꾸면, 프로필을 따르던 보는 지역도 따라간다. 직접 고른 지역은 그대로 두고 "내 지역으로"를 보인다.
- 구버전 키 `nongsadama.regionId`는 처음 한 번 옮기고 계속 같은 값으로 맞춘다(1.5 이하·열린 옛 탭 호환). 다른 탭의 변경은 따라온다(R12).

## 4. 저장 제안("내 지역으로 저장")
- 조건: 로그인, 프로필 행이 있음, 프로필 지역이 없거나 비활성, 직접 고른 유효한 지역을 보는 중, 그 지역을 "나중에"로 넘기지 않음.
- 저장: `profiles` PATCH(`id`·`region_id=is.null` 또는 이전 무효 값 조건, 본문 `region_id`만). 0행이면 다시 확인하고, 행이 없으면 가입 처리를 기다렸다가 한 번만
  다시 시도한다. 다른 기기에서 그사이 정했으면 제안을 거둔다. 서버가 돌려준 값으로만 보는 지역을 바꾼다.
- "나중에": 계정·지역마다 기억(최대 20). 새 지역을 고르면 다시 묻는다. 화면 읽기는 계정·지역마다 한 번 알린다.

## 5. 출시된 1.5와 함께 쓸 때
- DB 변경이 없어 1.5는 그대로 동작한다. 1.5는 가입 때 지역을 계속 복사하고, 지역이 없으면 전국을 보인다 — 업데이트하면 사라진다.
- 같은 사람이 웹(1.6)과 앱(1.5)을 같이 쓰면 저장소가 달라 서로 영향이 없다.

## 6. 되돌리기

- 부분 스위치: `src/config/app.ts` `regionSyncConfig.autoApply = false`(프로필 지역 자동 적용만 끔, "내 지역으로" 버튼은 남음).
