| 개인정보처리방침 §1·§4·§6·영문 요약, 계정 삭제 안내에 사진 | 오너 검토 |

## 3. 다른 지역 보기 제한(D-045)
- 내 지역: 로그인하면 프로필 지역(지금 고를 수 없는 지역이면 기기 지역), 로그인 전에는 기기에서 고른 지역. 글 수: 내 지역(시·군 범위)의 공개 글.
- 5개 이상이면 "다른 지역 보기"(시·도 → 시·군·구)로 둘러본다(기기 지역은 바꾸지 않음). 기기 지역이 내 지역 밖이면 그 지역을 보여 주고 "내 지역으로"가 생긴다.
- 잠김: 기기 지역이 내 지역 밖이면 내 지역 글 + 이유 + "프로필 수정" 링크. "다른 지역 보기"를 누르면 "지금 n/5개". 글 수를 못 세면 "–".
- 이웃의 글 보기·비슷한 글에서도 내 지역 밖 글을 숨김(숨긴 수를 알림). 링크로 받은 글 하나는 연다(공유 유지).
- 로그인 전: 기기 지역 글만. `?region=`은 무시. 지역이 없으면 전국 글 대신 "먼저 지역을 골라 주세요".
- 글은 내 지역 게시판에 올라간다(글쓰기에 "○○ 게시판에 올라가요"). 예전에는 기기 지역이 먼저였다.
- 앱 화면에서만 거른다(오너 선택). 게시글은 공개 읽기 그대로다.

## 4. 회원가입·계정 삭제 확인 단계(D-046)
| 요구 | 받아들임 기준 |
|---|---|
| 계정 삭제는 내 정보 맨 아래 "계정 설정" 칸 | 375×812 첫 화면에 계정 설정·회원탈퇴가 보이지 않음(제목 882px), 로그아웃은 첫 화면에 있음, 스크롤한 채 들어와도 맨 위 |
| 계정 설정에는 "회원탈퇴" 글자만 | 빨간 칸·계정 삭제 버튼은 회원탈퇴를 눌러야 펼쳐짐, 다시 누르면 접힘 |
| 회원탈퇴 → 계정 삭제 → 본인 확인 → 영구 삭제 확정 | 이메일 가입: 비밀번호 재입력(틀리면 안내, 삭제 요청 없음, 모르면 이메일 요청 링크). 카카오 가입: 숫자 4개(틀리면 안내, 전각·크메르·태국·네팔·몽골 숫자 허용). 취소하면 처음으로 |
| 두 번 누름 사고 방지 | 새로 나타난 버튼 350ms 무시, 확정 단계는 취소가 왼쪽·영구 삭제가 오른쪽, 영구 삭제는 1초 흐리게(점검: 삭제 요청 0) |
| 회원가입 비밀번호 확인 | 다르면 가입 요청 없이 안내, 같으면 가입 진행. 로그인 화면에는 칸 없음 |
