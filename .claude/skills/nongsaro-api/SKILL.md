# 농사로 OpenAPI 연동 스킬 (농사다마)

**전제**: 이 스킬은 운영자가 API 키를 전달한 뒤에만 구현을 시작한다.
키 없이 프록시를 미리 배포하지 않는다(미검증 엔드포인트/응답 구조를 코드로 굳히는 것 금지).

## 0. 운영자 선행 작업 (키 신청)

1. 농사로 공공데이터개방(nongsaro.go.kr → 공공Data개방) 또는 공공데이터포털(data.go.kr)에서
   활용신청(무료). 대상 서비스(우선순위):
   - **주간농사정보** — 홈/농사도움 상단 "이번 주" 섹션용
   - **병해충 발생정보** — 작목 태그 연계 경보
   - **농업기술 동영상(농영상)** — 1분 영상(저문해력 사용자에 최적)
2. 발급 키를 Claude에 전달(채팅) — 클라이언트에 넣지 않고 Supabase secret으로만 사용.

## 1. 아키텍처 (구현 시)

- **Edge Function `nongsaro`** (verify_jwt=false 고려 — 공개 읽기 데이터이므로; 남용 방지로
  간단 캐시 필수): `NONGSARO_API_KEY`는 `supabase secrets set`으로만 저장.
- 농사로 응답은 **XML** — 함수 안에서 JSON으로 변환해 반환. 필드 구조는 **키 발급 후
  실호출로 확인하고 나서** 타입을 정의한다(문서 추정 금지).
- **캐시**: 주간농사정보는 주 1회 변경 — `farm_api_cache(service, payload jsonb, fetched_at)`
  테이블에 24h 캐시 → 공공 API 호출 최소화(무료 원칙·rate limit 보호).
- 클라이언트: `useNongsaroWeekly()` 훅 — 함수 404/미설정 시 **섹션 숨김**(kakaoMap의
  env-gated 패턴과 동일, 무언 실패 아님 — 부가 콘텐츠).

## 2. 화면 통합 지점

- `src/pages/FarmTips.tsx` 상단: "📅 이번 주 농사" 카드(주간농사정보 요약 + 원문 링크).
- 병해충 경보: FarmTips 목록 상단 배너(작목 태그 일치 시 강조).
- 농영상: FarmTipDetail 하단 관련 영상 링크(임베드는 트래픽·CSP 검토 후).

## 3. 검증 절차 (기존 규율)

1. 키로 실호출 → 응답 XML 구조 기록(TEST_CHECKLIST에 샘플 저장)
2. Edge Function 배포 → curl로 JSON 변환·캐시 동작 확인(2회 호출 시 캐시 적중)
3. UI: 키 없음(로컬) → 섹션 숨김 / 키 있음(프로덕션) → 렌더
4. 독립 재검수(중점: API 키 유출 경로, 캐시 신선도, 응답 필드 방어적 파싱)
5. D-0XX 기록: 서비스 선택 근거·캐시 정책. /privacy 제3자 목록에 농사로(농진청) 추가.

## 4. 주의

- 농사로 콘텐츠 재게시 시 출처 표기(공공누리 유형 확인) — 상세 화면에 출처 필수.
- 번역: API는 한국어만 — en 사용자는 원문+farm.sourceNotice 안내(자동 번역은 별도 결정).
